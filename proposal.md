# Updated Proposal

## Project Title
NFC-Based Check-in/Check-out System for a Board Game Café

## Problem Statement

The current board game café operation has several problems that affect both customers and staff.

First, the existing website is inconvenient and not user-friendly for customers.

Second, stakeholders need a better way to promote and sell 3D-printed board game products.

Third, the current check-in and check-out process requires staff assistance. During busy periods, this can cause delays and increase staff workload.

Based on these problems, the project focuses mainly on improving the check-in and check-out process by using NFC technology.

## Target Users

### Primary Users
- Board game café customers
- Board game café staff

### Stakeholders
- Board game café owner
- Café staff
- Customers
- Stakeholders who want to promote or sell 3D-printed board game products

## Proposed Solution

The proposed solution is an NFC-based self-service check-in and check-out system.

Customers will receive an NFC tag and use it to check in when entering the café. After finishing their session, they can scan the NFC tag again to check out.

The system is intended to reduce waiting time, reduce staff involvement, and improve the overall customer experience.

## Main Objectives

- Reduce check-in and check-out time.
- Reduce staff workload during busy periods.
- Allow customers to complete check-in and check-out more independently.
- Improve customer satisfaction.
- Improve the usability of the café system.

## Expected Benefits

- Faster check-in and check-out process.
- Less dependency on staff.
- Better customer experience during busy periods.
- More efficient café operations.
